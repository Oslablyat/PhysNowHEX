Как устроен расчёт

Кнопка «Найти» выбирает неизвестный среди четырёх температур и двух расходов. Повторное нажатие возвращает ручной ввод. По умолчанию находится расход холодного потока. При всех заданных значениях проверяется баланс с допуском 0,1 %.

Змеевиковый аппарат — Teplo

Горячая вода проходит внутри змеевиков, холодная — в межтрубном пространстве. Поддерживается противоток. Свойства рассчитывает CoolProp 8.0.0 при абсолютных давлениях: массы фиксируются по плотностям на входе, теплоёмкости берутся при средних температурах потоков. Неизвестная температура находится численно с пересчётом свойств; для обратного поиска поддержана жидкая вода от 0,01 °C до температуры насыщения при заданном давлении минус 0,01 °C.

Qh = Gh · cp,h((Thi + Tho)/2, ph) · (Thi − Tho)
Qc = Gc · cp,c((Tci + Tco)/2, pc) · (Tco − Tci)
Qh = Qc
UAтреб = Q / ΔTlm

Расходы: кг/с, кг/ч, м³/ч, м³/с, л/с. Объёмный расход переводится по входной плотности CoolProp; при смене единиц физический расход сохраняется. Пока баланс не рассчитан, перевод известного расхода недоступен. Численное λw задаётся явно рядом с материалом; марка трубы автоматически его не подменяет.

Верхние выходные температуры — проектное задание. Для каждой конструкции полная поверка Teplo находит фактические выходы, Q, K, UA, α, Nu и Re. Постоянный заданный K для змеевиков не используется. Процент запаса относится к UA, не к площади. Площадь навивки берётся по среднему диаметру трубы, без отводов. Результаты вне применимости не принимаются в успешный подбор. Ручные правки геометрии поверяются отдельно; невыполнение задания или запаса явно показывается.

Кожухотрубный тип использует отдельную предварительную модель с постоянными cp и K, описанную ниже; её гидравлика не применяется к змеевикам. Прочность, загрязнения, фазовые переходы и потери давления по Teplo не рассчитываются.

Методика подбора вариантов

Змеевиковый аппарат: последовательный подбор по Teplo

При заданных наружном D и рабочей высоте L сначала оценивается стенка: s = ceil[(pабс,меж − 0,101325)D/(2 × 130 × 1) + 0,2] мм. Давление — МПа, диаметр — мм. Внутренний диаметр Ds = D − 2s. Это упрощённая предварительная оценка по заданной формуле, не полный расчёт прочности; вакуум и внешнее давление не проверяются.

По умолчанию труба 14×2,5 мм; можно включить уточнение типоразмера. Первый диаметр навивки по оси = Ds − d − 6 мм: зазор до внутренней поверхности корпуса 3 мм. По одному змеевику в радиальном ряду на всю рабочую высоту; целое максимальное число витков, затем шаг уточняется до высоты L с учётом наружного диаметра трубки. Между витками принят нормальный зазор не менее 3 мм. Если задание не выполнено, добавляется следующий ряд внутрь с радиальным зазором 3 мм. Диаметр вытеснителя следует за внутренним рядом с зазором 3 мм; стенка вытеснителя 2 мм. Отводы: радиус 2d, прямой участок max(40 мм, 2d).

Каждый шаг проверяется исходным Teplo: мощность, выходные температуры, запас UA, сходимость и критерии. По согласованию временно исключено только условие 3 < R/dᵢ < 12. Его предупреждения не удаляются: принятый результат с исключением не означает полной применимости исходной методики. «Оптимальная» — первая достаточная конструкция в этой последовательности, не глобальный оптимум. Пределы редактора: 1–8 рядов и до 1000 витков на змеевик; если вариант не найден, показывается причина. «По габаритам» и «По сложности производства» пока отключены; Δp отсутствует.

Подбор работает в фоне. Нажатие строки загружает конструкцию в проработку и 3D; повторное — восстанавливает её. Ручные правки и данные отдельных листов сохраняются и не затираются автоматическим подбором.

Кожухотрубный аппарат: отдельная предварительная модель

Следующая методика относится только к кожухотрубному типу и не используется для змеевиков. Подбор — с одним ходом по трубам, для жидкой воды в обоих контурах при 0…100 °C. Заданные L и D — верхние границы габаритов. Каждый вариант обеспечивает требуемую тепловую поверхность с введённым запасом при постоянном K = 800 Вт/(м²·К). K не уточняется по скоростям, материалу и геометрии.

Перебираются 7 длин (40…100% L), трубы 16 × 1,5; 20 × 2; 25 × 2; 32 × 2,5 мм, три значения количества труб, до четырёх диаметров корпуса и три шага перегородок. Флажок «Уточнить типоразмер труб» фиксирует d и δ. Минимумы относятся к этому набору кандидатов; критерии могут выбрать одну конструкцию.

  • Оптимальная конструкция: равный вес относительных объёма корпуса, мощности прокачки и сложности изготовления (среднее логарифмов отношений к минимумам).
  • По габаритам: минимум πD²L/4.
  • По гидравлике: минимум Δpт·ṁт/ρт + Δpм·ṁм/ρм.
  • По сложности производства: минимум 2n + 4Nпер. Это сравнительный показатель соединений труб и перегородок, а не расчёт трудоёмкости.

Компоновка: треугольная решётка с шагом 1,25d; стенка корпуса условно 5 мм, радиальный зазор пучка 10 мм. Трубы размещаются в узлах решётки от центра к периферии. Активная длина трубы 0,9L. Шаг сегментных перегородок 0,4…0,6 внутреннего диаметра корпуса. Пределы поиска: L ≤ 10 м, D ≤ 2 м, до 3000 труб.

F = πd·l·n
Δpт = (fт·l/dᵢ + 4)·ρтvт²/2
Δpм = exp(0,576 − 0,19 ln Reм)·(Nпер + 1)·Dᵢ/dэ·ρмvм²/2

Метод Керна для межтрубного пространства (400 ≤ Reм ≤ 10⁶). В трубах fт = 64/Re для Re ≤ 2300; 0,316 Re⁻⁰·²⁵ для 4000…20 000; 0,184 Re⁻⁰·² для 20 000…300 000. Переходный режим 2300…4000 исключён. Давление после потерь должно оставаться положительным.

Плотность и вязкость зависят от средней температуры каждого контура. Считается, что вода остаётся жидкой; проверка кипения и кавитации не выполняется. Патрубки, утечки, байпасные потоки, шероховатость, прочность и тепловая поправка на реальную компоновку не учитываются. Полученные Δp — предварительные оценки для сравнения вариантов.

Источники: BUET · расчёт теплообменников; ORNL · плотность воды. Вязкость: μ = 0,001[1 + 0,015512(T − 20)]⁻¹·⁵⁷² Па·с, аппроксимация для 0…100 °C.
