# Полная рабочая высота всех радиальных рядов — v8

Дата: 04.11.2026. Алгоритм `re-stock-full-height-v8`.

## Исправление

Ранее оптимизатор допускал разное число витков у радиальных рядов, чтобы
каждая трубка укладывалась в заготовку 1/3/6 м. Из-за этого часть рядов
заканчивалась раньше, и в 3D возникала ступенчатая компоновка.
Это допущение отменено по требованию владельца.

Теперь все ряды имеют одинаковое число змеевиков, одинаковое целое число
витков, общий шаг, фазу и направление. Смещение по высоте равно нулю.
Для каждого ряда обязательно `n × h + do = Hкорпуса`.
Центры начала навивки лежат на `H/2 − do/2`, центры окончания — на
`−H/2 + do/2`. Ни один радиальный ряд не укорачивается независимо.

Полные длины трубок при этом различаются из-за радиусов. Поэтому заготовки
проверяются одновременно для всех рядов при едином n и h. Если хотя бы
одна трубка не проходит заготовку, вся компоновка отклоняется.
Тепловая методика и её исходные корреляции не изменены.

## Ограниченный поиск

Для каждой каталожной/уточняемой высоты вычисляется верхняя граница общего
целого числа витков по минимальному шагу и длинам всех заготовок. Далее
выполняется только дешёвая геометрическая проверка общих витков; исходный
полный Teplo вызывается для уже изготовимой геометрии.

Предварительно вместимый N может оказаться несовместимым с заготовками при
полной высоте всех рядов. Такие N не занимают тепловые резервные слоты.
Дешёвые каталоги совместимых N ранжируются по оценке UA, затем до четырёх
N допускаются к полному Teplo. Это позволяет при больших верхних габаритах
сохранить перспективные короткие варианты. Общий бюджет по всем этапам
остался 200 полных вызовов, включая ошибки; дубли не пересчитываются.

## Проверенные соседние задания

Горячая вода 90→60 °C, 2,5 кг/с, 0,6 МПа абс.; холодная вода до 40 °C,
0,4 МПа абс., расход по балансу; λw=16, трубка 14×2,5 мм, запас 0 %,
верхние L=2000 мм и D=600 мм.

| Холодный вход, °C | N | Радиальных рядов | Корпус H×D, мм | Qфакт, кВт | Избыток Q | Полных проверок |
|---:|---:|---:|---|---:|---:|---:|
| 20 | 48 | 2 | 1952×232 | 314,732107 | +0,102851 % | 114 |
| 21 | 48 | 2 | 1926×232 | 314,569874 | +0,051252 % | 114 |
| 31 | 54 | 3 | 1955×236 | 314,433086 | +0,007745 % | 67 |

Q задания во всех трёх случаях — 314,408734 кВт. Для холодного входа 31 °C
в каждом из трёх рядов 18 змеевиков, по 3 витка, общий шаг 647 мм.
Каждая навивка занимает `3×647 + 14 = 1955 мм` рабочей высоты.

## Проверки

- Геометрия приложения, точные полные длины трубок, заготовки и все условия
  приёмки Teplo проходят для трёх заданий. Их независимый пересчёт исходным
  Python Teplo / CoolProp 8.0.0 совпал.
- Тест пересечений реальной 3D-осевой линии проверяет коридорное выравнивание
  под пятью азимутами. Отдельно проверяются общие верхние и нижние точки
  осевых линий всех навивок в отрисовываемой модели.
- Прежняя ступенчатая геометрия v7 отвергается новым геометрическим условием.
  Нарушение общего числа витков также блокирует проектную приёмку.
- Проверяются запрет ненулевого общего верхнего отступа, соответствие H,
  общий бюджет 200, максимум четыре тепловых резервных N, отсутствие дублей
  и отмена расчёта во время уточнения.
- Ручная геометрия листов сохраняется. После изменения вручную поверка может
  показать числа, но нарушенная полная высота не подтверждается как оптимум.
- Полная серия 150 заданий в v8 не запускалась. Старые результаты v6/v7
  относятся к прежнему допустимому множеству; их проценты не выдаются за v8.
