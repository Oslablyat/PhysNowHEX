# Коридорная геометрия оптимальной конструкции — v6

Дата: 04.11.2026. Версия re-stock-inline-v6.

## Новое обязательное условие

Оптимальная конструкция имеет одинаковое число змеевиков во всех радиальных рядах, общий шаг навивки, общий верхний уровень, начальный угол 0° и правое направление. Для любого продольного сечения центры труб соседних рядов лежат на одной осевой решётке с периодом h/Nряда. Разное число витков допускается для размещения каждой полной трубки в заготовке 1/3/6 м: ряды могут заканчиваться раньше друг друга, сохраняя выравнивание в общей активной части.

Распределения трубок с весами R и R² удалены. Общее N должно делиться на число радиальных рядов. Полная длина, Re, зазоры, диапазон радиусов, допуск мощности и выходных температур не ослаблялись. Первая партия 20 и общий бюджет 200 сохранены. Подбор и загружаемый в редактор результат всегда используют inline; ручная геометрия не перестраивается.

## Проверки

- Тест реальной 3D-осевой линии пересекает змеевики продольными полуплоскостями под пятью углами, включая произвольные, и проверяет совпадение высот центров в общей рабочей зоне.
- Проверены отказы при несовпадении числа змеевиков, шага, смещения, фазы или направления.
- Тепловая приёмка не подтверждает проектный оптимум при несовпадении шагов/количеств. Интерфейс дополнительно проверяет фактическую фазу/смещение/направление и выбранную корреляцию.
- Исходный Teplo и его численные корреляции не изменены. Полный npm test и npm run check пройдены.

## Повторная серия 150 заданий

15 расходов 0,02…80 кг/с × 10 температурных режимов. Вода/вода, противоток, труба 14×2,5 мм, запас 0 %, λw=16; абсолютные давления 2 / 1,2 МПа. Предельные L=10 м, D=3 м не фиксируются равенством.

Найдено **55/150** конструкций. Все 55 имеют коридорную геометрию, прошли проверку размеров приложения, полной длины и заготовок, повторный исходный Teplo и независимый Python Teplo / CoolProp 8.0.0. Нарушений приёмки — 0; максимум полных вызовов на сценарий — 200.
