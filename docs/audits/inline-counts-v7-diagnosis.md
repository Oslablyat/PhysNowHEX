# Разбор отказов коридорного подбора и исправление v7

Дата: 04.11.2026. Текущая версия: `re-stock-inline-counts-v7`.

## Случай со скриншота

Вода/вода, противоток, горячий поток 90→60 °C, 2,5 кг/с, 0,6 МПа абс.;
холодный 31→40 °C, расход находится по балансу, 0,4 МПа абс.
Трубка 14×2,5 мм, λw=16, запас 0 %, предельные L=2000 мм и D=600 мм.

Баланс корректен: Qзад=314,408733989 кВт, холодный расход ≈8,3605 кг/с.
Предварительный Re разрешает N=47…62, основное N=54.

v6 пробовал резервы 53, 55, 47 и 62. 53 и 47 не образуют допустимых
многорядных коридорных компоновок: эти числа простые, а в один ряд столько
трубок не помещается. Для 54 в проверенном каталоге ближайшая применимая
мощность была выше задания на 3,026 %, для 55 — ниже на 6,326 %.
До подходящего N=56 поиск не доходил. Это подтверждённый пропуск поиска,
а не ошибка баланса и не доказательство невозможности аппарата.

После исправления резерв: **55, 62, 52, 56**. Слоты не занимают заведомо
невместимые количества; дополнительные N получаются как допустимые кратные
числу радиальных рядов. Проверяются вместимость по хорде и минимальному
шагу на существующей сетке радиусов. Полный Teplo, заготовки и приёмка
остаются обязательными; резерв ограничен четырьмя N, общий бюджет — 200.

Рабочий алгоритм v7 самостоятельно получил:

| Параметр | Результат |
|---|---:|
| Общее число трубок | 56 |
| Радиальных рядов | 4 |
| Трубок в каждом ряду | 14 |
| Рабочая высота корпуса | 1920 мм |
| Наружный диаметр корпуса | 230 мм |
| Общий шаг навивки | 381,2 мм |
| Qзад | 314,408734 кВт |
| Qфакт | 314,863433 кВт |
| Избыток мощности | +0,144620 % |
| Полных расчётов | 124 |

Геометрия, Re, исходная применимость, выходные температуры, все полные длины
и заготовки проходят условия. Результат независимо совпал с исходным Python
Teplo / CoolProp 8.0.0. Это также проверено в интерфейсе локального сайта.

## Почему восемь прежних заданий остались без результата

Все восемь старых выбранных геометрий v5 не удовлетворяют новой проверке
коридорной геометрии. Их нельзя просто сохранить как новые оптимальные
коридорные варианты. При этом отсутствие найденной замены — отдельный вопрос:
оно не означает автоматически физическую невозможность.

После исправления резерва N эти восемь сценариев перепроверены v7:

| Сценарий | Горячий, °C | Холодный, °C | Горячий расход, кг/с | Результат поиска v7 |
|---|---|---|---:|---|
| B-5 | 70→50 | 15→35 | 5 | 42 проверки; сокращённый каталог и локальные уточнения без приёмки |
| C-5 | 90→60 | 20→40 | 5 | Нужно N≥94; коридорных семейств нет |
| D-1 | 90→80 | 20→30 | 1 | Лимит 200 |
| D-2.5 | 90→80 | 20→30 | 2,5 | Лимит 200 |
| F-2.5 | 120→70 | 20→60 | 2,5 | Лимит 200 |
| G-0.08 | 150→90 | 30→70 | 0,08 | Лимит 200 |
| G-2.5 | 150→90 | 30→70 | 2,5 | 34 проверки; сокращённый каталог и локальные уточнения без приёмки |
| H-2.5 | 160→60 | 10→100 | 2,5 | 62 проверки; сокращённый каталог и локальные уточнения без приёмки |

Для C-5 есть отдельная геометрическая верхняя оценка. При di=9 мм требуется
R<108 мм. С радиальным межосевым шагом 17 мм и одинаковым количеством трубок
в каждом ряду максимальная вместимость по хорде, даже без сетки радиусов:

| Радиальных рядов | Верхняя граница внутреннего R, мм | Максимум трубок в ряду | Всего |
|---:|---:|---:|---:|
| 1 | 108 | 39 | 39 |
| 2 | 91 | 33 | 66 |
| 3 | 74 | 27 | 81 |
| 4 | 57 | 20 | 80 |
| 5 | 40 | 14 | 70 |

Шесть рядов не помещаются между строгими границами 27<R<108 мм при шаге 17 мм.
Верхняя оценка 81 меньше требуемых 94. В принятой модели коридорных рядов
эти требования несовместимы; увеличение наружного корпуса не отменяет R/di.
Это вывод для текущего типоразмера и ограничений, не для любых теплообменников.

Для остальных семи сценариев физическая невозможность не доказана.
Дополнительная диагностика отдельно проверила до 400 первых каталожных точек
для каждого целого N из предварительного диапазона Re; подходящего варианта
не нашла. Это тоже конечная сетка, без доказательства отсутствия решения
между её точками. Полные потери давления/прочность этой проверкой не добавлены.

## Проверки исправления

- Сценарий со скриншота и соседние холодные входы 20 и 21 °C прошли полный
  подбор, геометрию, заготовки и независимый Python Teplo.
- Перепроверены 20 затронутых сценариев: 12 ранее успешных случаев с резервным
  N и восемь отказов. Все прежние 12 решений сохранились; все 12 результата
  независимо сверены с Python. Восемь отказов остались с причинами выше.
- `npm run check` и полный `npm test` пройдены. Добавлен отдельный регрессионный
  тест `tests/test-inline-reserve-counts.cjs`, включая N=56 и проверку того,
  что резервные N действительно имеют допустимые радиальные семейства.
- Вязкость по-прежнему вычисляется один раз для предварительного N.
  Дополнительные проверки вместимости не вызывают Teplo. Максимум резервов
  4, максимум полных вызовов на задание 200, исходные корреляции не изменены.
- Полные 150 сценариев в v7 заново не прогонялись; результаты серии v6
  сохранены как исторические и не выдаются за измерения v7.
