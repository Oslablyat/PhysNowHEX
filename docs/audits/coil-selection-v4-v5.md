# Сравнение подбора v4 → v5 на тех же 150 сценариях

Дата: 04.11.2026. До: re-stock-matched-v4; после: re-stock-refined-v5.

## Условия

Входные состояния совпадают побайтно после JSON-сериализации. 15 расходов горячей воды 0,02…80 кг/с × 10 температурных режимов, расход холодной стороны решается из баланса. Вода/вода, противоток, коридорное расположение, труба 14×2,5 мм, λw=16, запас 0 %. Давления 2 / 1,2 МПа абсолютных. Верхние габариты L=10 м и D=3 м, без требования заполнять их. Ограничения приёмки и исходный Teplo не изменены.

В 2 сценариях найденная конструкция использует резервное N. Медиана полных вызовов среди сценариев, дошедших до Teplo: v4 40, v5 200.

Улучшение надёжности и геометрии потребовало больше расчётов внутри прежнего лимита 200. Числа времени получены при разной параллельной нагрузке и состоянии кэшей, без начальной загрузки WASM; это не контролируемый браузерный бенчмарк. Ускорение не заявляется.

## Контрольный пример длины

A-2.5: корпус 1006×212 мм заменён на 878×226 мм. Длина уменьшена на 128 мм (12.72 %). Мощность 104.461185 кВт при задании 104.391407 кВт.

## Что проверено

Каждая из 63 выбранных геометрий прошла валидатор приложения, точный расчёт полной длины с обоими отводами и концами, правила заготовок 1/3/6 м, зазоры, целые витки, полный повторный Teplo, Q=0…+1 %, выходные температуры и Re. Все 63 результата независимо совпали с исходным Python Teplo + CoolProp 8.0.0.

Регрессионные тесты отдельно проверяют четыре доказанных пропуска, улучшение длины, резервное N при недоступности основного, отмену в уточнении, отсутствие дублей и реальный общий предел 200 вызовов, включая исключения. Полный npm test и npm run check пройдены.

## Ограничения

Сетка радиусов и семейств остаётся дискретной. Локальные уточнения ограничены окрестностями перспективных точек; резерв N ограничен четырьмя значениями. Глобальный минимум и физическая невозможность отказавших заданий не доказываются. Re, диапазон R/di, заготовки и другие критерии не ослаблялись. Режимы с тесным сближением температур могут оставаться без решения.
