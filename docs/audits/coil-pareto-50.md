# Проверка подбора змеевиков на 50 тепловых режимах

Проверялся основной локальный решатель `inline-pareto-v1`. Проведено 90 запусков на 50 различных сочетаниях температур, расходов и абсолютных давлений. Десять опорных тепловых заданий проверены в пяти исполнениях. Ещё 40 тепловых заданий рассчитаны в одном исполнении каждое. В основной выборке взято по одному запуску каждого теплового режима и ровно по десять запусков каждого типа конфигурации. Ещё 40 запусков образуют контрольную серию на тех же опорных тепловых заданиях. Это целевая испытательная сетка, по ней нельзя оценивать вероятность успеха на будущих заказах.

Для каждого запуска перехвачены фактические вызовы Teplo с проверкой уникальности входов, счётчиков и предела. Для всех принятых строк повторно проверена геометрия редактора. Независимый геометрический поиск ниже проверяет пропуски вне этой таблицы. Оба поиска используют одну тепловую модель. Стендовых измерений в этой работе нет.

## Независимые конструкции

Штатные R₁ = 28, 33, 38… мм сравнены с целыми радиусами начиная с 28 мм. Трубка 14 × 2,5 мм, зазоры до стенок 3 мм, минимально достаточный диаметр корпуса, корпус по штатной формуле. Для N=1 с заготовками проверены все изготовимые сочетания радиусов, вертикальных зазоров и витков в этой дискретной области. Для обычных заданий отдельно строились аппараты с одним или двумя рядами. Если уже есть рекомендация, перебирались только конструкции, способные строго улучшить её хотя бы по одному критерию без ухудшения остальных. Предел испытания таких кандидатов — 1200. Исследование не сертифицирует оптимум по всем вещественным радиусам, диаметрам корпуса и типоразмерам труб.

## Сколько поверок можно убрать

В каждой строке следующей таблицы взяты первые фактические вызовы штатного поиска до указанного лимита. Приёмка и рекомендация заново рассчитаны по этому префиксу. Совпадение проверено по физическому ключу конструкции. Сохранённые точки — пересечение фронта префикса с полным штатным фронтом. Сопоставление с бюджетом 10 000 относится к текущей сетке сайта. Смена очереди при внедрении нового алгоритма потребует отдельного прогона.

Для более экономного поиска проверены два разных приёма.

1. **Поиск диапазона витков по мощности.** При фиксированных радиусах, числе трубок и шаге отсортировать допустимые целые витки, включая интервалы заготовок. Полными поверками делить диапазон пополам, найти нижнюю и верхнюю границы мощности и проверить все внутренние варианты по температурам, Re, UA и геометрии. При ошибке на опорной точке воспроизведение переходит к полному перебору семейства. Ниже — ретроспективное сравнение на полностью просчитанных каталогах. Во всех этих семействах проверено отсутствие убывания измеренной мощности при увеличении числа витков. Для новых областей нужна отдельная проверка монотонности или обоснованные границы, поскольку пропущенный разворот между опорными точками невозможно обнаружить одной бисекцией.

|---|---:|---:|---:|---:|---:|---:|
| 5 однорядных каталогов с заготовками, сетка 1 мм | 27 270 | 12 913 | 52,6 % | 415 | 0 | 0 |
| 5 обычных штатных каталогов с заготовками | 8 840 | 7 511 | 15 % | 484 | 0 | 0 |

2. **Отсев по пяти известным до поверки размерам.** Для таблицы лучших компромиссов можно пропускать кандидата, если уже поверенный аппарат с полной применимостью строго доминирует над ним. Проверка должна быть строгой хотя бы по одному показателю. Аппарат с исключением по Re не должен отсекать потенциально полностью применимый вариант. При обходе по возрастанию H, затем D, такой отсев пропустил 8 861 из 27 270 поверок пяти однорядных каталогов (32,5 %), сохранив точный фронт в каждом. При запросе «Все подходящие» отложенные доминируемые аппараты всё равно придётся проверить. Экономию двух приёмов нельзя складывать.

Для сайта предлагается сначала выдавать предварительный фронт, затем уточнять внутренние радиусы между штатными узлами, включая соседей лучших и близких к допуску аппаратов. Нужен также отдельный проход по пропущенным радиусам у семейств с пустым результатом, иначе №34 останется незамеченным. Часть бюджета сохранять для слабо исследованных N и чисел рядов. Поиск диапазона витков включать сначала в проверенных областях. Лимит 10 000 оставить общим для всех этапов. Увеличивать число строк в таблице и уменьшать число поверок можно оценивать раздельно по сохранённым принятым строкам, точкам фронта и совпадению рекомендации.
