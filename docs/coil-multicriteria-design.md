# Многокритериальный подбор змеевиков

Установленная версия основного локального сайта от 08.11.2026 — `inline-pareto-v2`. Пользователь задал потолок **1 000 полных вызовов Teplo на одно задание** и допуски **3 % по мощности и выходным температурам**. Сравнение на тех же режимах приведено в [испытании версии с лимитом 1 000](audits/coil-pareto-1000.md). Ниже сохранены также результаты предыдущей версии с лимитом 10 000. Работу установленной версии описывает [инструкция по основному подбору](coil-algorithm-agent-guide.md).

## Что считать выполнением задания

- Принять мощность от `Qзад` до `1,03 × Qзад` включительно с прежним численным допуском на границах.
- Для горячего выхода принять интервал от `Tho − 0,03 × (Thi − Tho) − 0,01 °C` до `Tho + 0,01 °C`. Для холодного выхода принять от `Tco − 0,01 °C` до `Tco + 0,03 × (Tco − Tci) + 0,01 °C`. Так сохраняется направление прежних допусков. Для задания 90 → 60 °C и 20 → 40 °C интервалы равны 59,09…60,01 °C и 39,99…40,61 °C.
- Действуют требования к UA (запас 0 %), исходным критериям Teplo, наружным габаритам, зазорам, вместимости и отсутствию пересечений. В обычном режиме проверить Re **каждой** трубки 15 000…20 000 и для всех рядов `3 < R/di < 12`.
- В режиме одного змеевика использовать строго N=1. Исключение по трубному Re сопровождает явная отметка о применимости. Для авторекомендации сначала рассматривать варианты с выполненными исходными критериями Teplo. Если доступны только варианты с разрешённым исключением, показывать предупреждение у рекомендации и строки.
- При включённых заготовках каждую полную трубку с обоими отводами и концами сопоставлять с заготовкой 1, 3 или 6 м, с остатком до 20 % и длиной строго меньше заготовки. Флажок независим от N=1.

## Геометрия нового поиска

Владелец подтвердил общую рабочую высоту с совпадающими серединами, верхними и нижними уровнями всех рядов, а затем выбрал только коридорное расположение. Разрешение неоднозначности между общими уровнями и разными шагами владелец передал разработчику. Для автоматического подбора принята **фактическая коридорная навивка по всей высоте**. Во всех рядах одного аппарата совпадают число заходов k, шаг P, целое число витков n, фаза и направление навивки. Высота `H = nP + dₒ`, осевое смещение равно нулю. У разных аппаратов могут быть разные шаги и число витков.

Действуют пределы 1–8 рядов, до 64 трубок на ряд, до 500 всего, до 1 000 витков. Исходные условия пробы — фаза 0°, правая навивка, 3 мм до корпуса и вытеснителя. Вертикальный зазор **внутри** ряда берётся по существующей целой сетке, для Ø14 это 2…14 мм. Для каждого аппарата `P = k(dₒ + s)`.

Для каждой **пары соседних рядов** измерять радиальное межосевое расстояние `S = Rᵢ₊₁ − Rᵢ`. Требуется `1,1dₒ ≤ S ≤ 1,5dₒ`, а чистый радиальный зазор `g = S − dₒ` кратен 0,5 мм. Диагональный зазор исключён из правил подбора по указанию владельца. Для Ø14 допустимы чистые промежутки 1,5, 2, 2,5, …, 7 мм, межосевые расстояния 15,5…21 мм. Для произвольного dₒ нижняя граница промежутка равна `ceil(2 × 0,1dₒ) / 2`, верхняя равна `floor(2 × 0,5dₒ) / 2`, все длины в мм. До стенок и вдоль оси аппарата действуют отдельные правила.

Строить многорядную конструкцию последовательно от внутреннего ряда. Для каждого N, числа рядов и внутреннего радиуса выбрать общий шаг P из допустимой целой вертикальной сетки. Добавлять по одному соседнему радиусу, перебирая допустимую сетку чистых радиальных зазоров. Для каждой пары можно выбрать свой зазор. На каждом шаге проверять вместимость, предварительную стенку корпуса и наличие места для остальных рядов. Для каждого добавленного радиуса пересекать списки целых n, удовлетворяющих габариту и, при включённом учёте заготовок, точной длине трубки данного ряда. Полная компоновка получается для каждого n из общего пересечения. В большом каталоге держать несколько разных частичных компоновок для каждого N и числа рядов. Радиальные сочетания в крупном каталоге выбираются по равномерно распределённым номерам допустимых последовательностей, дополнительно учитываются равномерные зазоры. После удачных поверок очередь уточнения получает соседние шаги и числа витков. В заключительном обходе преимущество получают мало проверенные семейства радиусов и шагов.

Учёт навивки, двух отводов и двух прямых концов выполняется для каждого ряда отдельно. В таблице показана разница длин самой длинной и самой короткой параллельной трубки, в метрах. Исходный Teplo делит расход поровну и использует это допущение при вычислении Re. Фактическое распределение потока и Δp требуют гидравлической модели.

Проверять совмещение рядов до Teplo. Например, при пяти заходах 6 витков с шагом 100 мм и 5 с шагом 120 мм занимают одинаковые 600 мм между концами осей, но уровни труб в продольном сечении идут через 20 и 24 мм. Такой аппарат отсеивается геометрически. Для каждой прошедшей геометрии вычислять Teplo с `arrangement=inline`. [Локальная методика, разделы 1–3](../assets/teplo-methodology.md)

## Как получить набор конструкций

1. Построить каталог дискретных семейств для **всех** целых N в принятом предварительном диапазоне Re. Для каждого N перебрать совместимые количества рядов, радиусы и параметры навивки. Начинать с геометрии, габаритов и заготовок. Оценочный UA задаёт порядок полных поверок.
2. Первые 100 поверок распределяются между группами по числу трубок и рядов. По измеренному UA уточняется оценка нужного числа витков. На этапах до 450 и до 700 поверок чередуются варианты, близкие к заданию, и кандидаты предварительного фронта по пяти показателям. После обхода других семейств до 800 поверок проверяются соседи принятого фронта с меньшим радиусом, радиальным или осевым зазором. Общий предел для поиска и диагностики — 1 000.
3. После партии полных поверок сравнить расчётный UA с приближённым для соответствующих семейств. Уточнять очереди по этой поправке и проверять дискретных соседей лучших кандидатов. Сохранять очередь на другие семейства даже при первом успехе или большой ошибке приближения. Длинная конструкция с меньшим диаметром или расходом трубы должна получить шанс на проверку.
4. Считать фактические вызовы `Teplo.calculate` до их выполнения, включая вызовы с ошибкой и отдельную диагностику габаритов. Кэш результата привязан к полному набору тепловых входов и заданию. Идентичность выбираемой конструкции учитывает также её механическую геометрию. Диагностика за пределами заданных габаритов расходует только свободный остаток бюджета и используется для объяснения отказа.
5. Завершить поиск при исчерпании кандидатов, достижении общего бюджета или отмене при изменении задания. Сообщать число проверенных, прошедших приёмку и вошедших в набор компромиссов. При достижении лимита вывод относится только к проверенной части каталога.

## Как выбрать лучшую

У каждой принятой геометрии сравниваются пять наблюдаемых величин, все на уменьшение.

| Показатель | Как посчитать |
|---|---|
| Расход трубы M, м | При учёте заготовок суммировать закупаемые метры по всем трубкам. При выключенном флажке суммировать фактические длины с отводами и концами |
| H, мм | Рабочая длина корпуса по принятой в приложении модели |
| D, мм | Наружный диаметр корпуса |
| N, шт. | Число параллельных трубок, которым суммарно нужны 2N концов |
| Число рядов | Число концентрических рядов навивки |

Сначала оставить **фронт Парето**. Конструкция уступает, если другая принятая конструкция хотя бы так же хороша по всем пяти величинам и строго лучше хотя бы по одной. Геометрии с равными показателями сохраняют свои идентификаторы для ручного выбора. Количество трубок и рядов описывает сборку в физических единицах. Для расчёта себестоимости потребовались бы расценки производства.

Для одной рекомендации решатель минимизирует наибольшее относительное отставание по пяти показателям. На найденном фронте перевести каждый показатель в шкалу от 0 до 1 по формуле `(x − минимум) / (максимум − минимум)`. Постоянный показатель даёт 0 всем конструкциям. Побеждает строка с наименьшим максимумом пяти чисел. При равенстве сравнить их сумму, затем стабильный ключ геометрии. Считать по исходной точности, округлять при выводе. Крайние точки определяются заново для каждого завершённого поиска, поэтому дополнительные поверки могут изменить рекомендацию. Это конкретное стартовое правило при отсутствии предпочтений по стоимости и габаритам. [Метод опорной точки, А. Вежбицкий, IIASA](https://pure.iiasa.ac.at/id/eprint/1117/7/WP-79-066.pdf)

В таблице открыть набор компромиссов и выделить рекомендацию. Для неё показать разницу в миллиметрах, метрах трубы и числе рядов относительно крайних вариантов. Дать доступ ко всем принятым конструкциям, включая близкие варианты с другим шагом или числом витков. Число строк определяется результатом поверок. Разделить отметку рекомендации и выбор для проработки, сохранять ручную геометрию листа при сортировке и пересчёте. При больших выборках выводить строки порциями и загружать выбранную геометрию из текущего Worker-кэша.

## Архив. 26 компромиссов предварительной пробы

Условия те же, горячий расход 0,5 кг/с, заготовки выключены. Все геометрии коридорные на полную высоту. Сетка внутреннего радиуса начинается с 28 мм и идёт с шагом 5 мм. Для трёх и более рядов добавлены два порядка чередования 1,5 и 7 мм. Это выборка сочетаний на согласованной сетке.

Для повторения пробы перебирать N, делители N по возрастанию, последовательности зазоров, внутренние радиусы, целые вертикальные зазоры и целые витки. В каждой группе (N, число рядов) упорядочить геометрии по близости оценочного UA к 1,015 × UAзад, как в первой пробе.
