# PhysNowHEX

PhysNow — рабочее пространство для расчёта теплообменников.

Статический сайт на HTML, CSS и JavaScript. Откройте index.html или разместите файлы на GitHub Pages.

Включены проектировочный расчёт, сравнение конструкций, карточка выбранного аппарата и редактор геометрии змеевиков с динамическими видами сверху и сбоку.

Поверочная страница змеевиков пока выполняет геометрические вычисления; тепловая и гидравлическая модели для неё не подключены.

Листы сохраняются локально в браузере. Данные localhost автоматически не переносятся на домен GitHub Pages.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Все ресурсы используют относительные пути. Сборка и серверные зависимости не нужны.
